### 一、总体目标

- **代码目标**：在不改变算法逻辑的前提下，仅修改 `problem/src/image_algorithms_optimize.cpp`，对六个图像处理算法进行体系结构相关优化，使在 **-O0** 编译下，相比基准实现有明显性能提升（争取整体加速比 ≥ 2×，有余力可冲击 ≥ 10× 的局部算法）。
- **报告目标**：完成一份结构完整的实验报告，包含环境说明、性能瓶颈分析、优化设计、关键实现、性能对比、正确性验证和总结反思。

### 二、工作阶段与步骤

#### 阶段 1：环境搭建与代码熟悉（0.5–1 天）

- **环境准备**
  - 确认本机架构（x86/64 或 arm64）与可用 SIMD 指令集（如 `cat /proc/cpuinfo | grep flags` 或 macOS 对应命令）。
  - 安装编译器（`g++` 或 `clang++`）与 CMake，确保支持 C++17 及以上。
- **编译与运行基准版本**
  - 在 `problem/` 目录下构建：
    ```bash
    mkdir build && cd build
    cmake ..
    make
    ./image_benchmarks_baseline
    ```
  - 熟悉 `baseline` 输出的 **正确性验证** 与 **性能测试** 格式，记录各算法在小/中/大图像规模下的初始时间。
- **阅读与理解基准代码**
  - 通读 `include/image_algorithms.hpp`，理解 `Image` 数据结构及各算法接口。
  - 详细阅读 `src/image_algorithms.cpp`，梳理六个算法的功能和时间复杂度：
    - 高斯滤波 `gaussianFilter`
    - 幂次变换 `powerLawTransformation`
    - Sobel 边缘检测 `sobelEdgeDetection`
    - 图像转置 `transpose`
    - 均值滤波 `boxFilter`
    - 图像旋转 `rotate90Clockwise`
  - 同时打开 `src/image_algorithms_optimize.cpp`，了解当前优化版本的实现框架（若为空或简单调用基准，可自行设计结构）。

#### 阶段 2：性能基线测量与瓶颈分析（0.5–1 天）

- **建立可重复的性能测试流程**
  - 使用 `./image_benchmarks_baseline` 获取基准性能。
  - 使用 `make image_benchmarks_optimized && ./image_benchmarks_optimized` 测试优化版本。
  - 使用 `make compare` 生成 `baseline.json` 与 `optimized.json`，作为报告中的对比数据来源。
- **使用性能分析工具定位热点**
  - 在 Linux 上：
    ```bash
    perf stat -e cache-misses,cache-references,instructions,cycles ./image_benchmarks_baseline
    valgrind --tool=cachegrind ./image_benchmarks_baseline
    ```
  - 分析哪几个算法耗时最多、缓存未命中率较高，为后续优化排序：**优先优化耗时占比最高的算法**（通常是高斯滤波、均值滤波和 Sobel）。

#### 阶段 3：逐算法优化实现（3–5 天）

整体策略：从 **易于优化且收益大的算法** 开始，先保证 **功能正确** 再逐步引入更激进的优化（SIMD、多线程）。

##### 3.1 高斯滤波 `gaussianFilter`

- **优化方向**
  - 利用卷积核常量展开（当前已展开），进一步：
    - **SIMD 向量化**：按行加载相邻像素，用 SSE / AVX2 / NEON 做乘加。
    - **循环展开与减少 `at()` 调用**：改用指针或行首指针+偏移减少函数调用开销。
    - 合理处理边界，仅对内部区域进行向量化。
- **任务**
  - 在 `image_algorithms_optimize.cpp` 中实现优化版，并通过与基准输出的 `calcChecksum` 或 `compareImages` 验证正确性。
  - 记录与基准的性能差异。

##### 3.2 幂次变换 `powerLawTransformation`

- **优化方向**
  - 使用 **查找表 LUT** 替代逐像素 `std::pow` 调用：
    - 初始化 `unsigned char lut[256]`，预先计算 \(\gamma = 0.5\) 的变换。
    - 逐像素用 `output[i] = lut[input[i]]`。
  - 可进一步用 **SIMD 批量加载/存储**。
- **任务**
  - 完成 LUT 实现并验证与基准差异（允许极小浮点误差时可用 `compareImages` + 容差）。
  - 测量加速比。

##### 3.3 Sobel 边缘检测 `sobelEdgeDetection`

- **优化方向**
  - 避免 `sqrt`，改用：
    - 保持 \(G_x^2 + G_y^2\) 的平方和，转为近似比较或快速近似函数；
    - 或使用 `std::min(int(std::abs(gx)+std::abs(gy)), 255)` 近似梯度强度（需确认是否符合“不改变算法逻辑”的要求，可在报告中说明）。
  - 对内部区域进行 **SIMD 向量化**，一次处理多个像素。
- **任务**
  - 完成无 `sqrt` 的实现，并确保视觉效果和基准接近（用 `compareImages` + 容差验证）。
  - 测试性能提升。

##### 3.4 图像转置 `transpose`

- **优化方向**
  - 实现 **缓存分块（blocking）**：
    - 选取合适块大小（如 32×32 或 64×64），块内做局部转置，减少缓存行冲突。
  - 若有精力，块内再做 SIMD 优化。
- **任务**
  - 在优化版中实现分块转置，与基准结果逐像素对比。
  - 对不同图像尺寸测量性能变化。

##### 3.5 均值滤波 `boxFilter`

- **优化方向**
  - 使用 **积分图（积分图像 / summed area table）**：
    - 先 O(WH) 构建积分图，再 O(1) 得到任意窗口和，将总体复杂度从 O(WHK²) 降到 O(WH)。
  - 结合 **SIMD** 对构建积分图和输出进行优化。
- **任务**
  - 设计并实现积分图版均值滤波（注意边界与 kernel_size 兼容）。
  - 重复正确性与性能评估。

##### 3.6 图像旋转 `rotate90Clockwise`

- **优化方向**
  - 对目标图像按行遍历，源图像按列访问时尽量保持源/目标访问连续：
    - 结合缓存分块减少跨行跳跃。
  - 如有精力，再对内层循环进行 SIMD。
- **任务**
  - 实现缓存友好的旋转，并验证输出正确性。

##### 3.7 多线程并行化（可选进阶）

- 根据时间和平台支持情况，对最耗时的 1–2 个算法（如高斯、均值滤波）加入 **OpenMP 并行 for**：
  ```cpp
  #pragma omp parallel for
  for (size_t i = 0; i < height; ++i) {
      // ...
  }
  ```
- 控制线程数：
  ```bash
  export OMP_NUM_THREADS=4
  ```
- 在报告中分别展示单线程与多线程的性能数据。
