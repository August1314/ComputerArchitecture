## 📚 关键发现

### 状态空间爆炸原因

MSI协议状态空间爆炸的根本原因是**并发执行路径的组合爆炸**，而不是状态机的复杂度。

**核心洞察**:
- SCI协议（3处理器，100+状态）→ 18,193个状态
- MSI协议（3缓存，3状态）→ 398,483个状态

**原因**:
1. 侦听协议的分布式特性
2. 缺乏序列化机制（无Pending状态）
3. 多个缓存可以同时操作
4. Murphi探索所有可能的执行交错

详见 `状态空间爆炸最终分析.md`
