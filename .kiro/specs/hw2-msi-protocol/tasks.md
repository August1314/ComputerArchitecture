# 实现计划

- [x] 1. 环境配置和验证
  - 安装必需的依赖包（build-essential、flex、bison、g++-multilib）
  - 编译Murphi源码，生成mu可执行文件
  - 验证Murphi安装正确性（运行SCI协议示例）
  - 确保源文件使用LF行尾符而非CRLF
  - _需求: 6.1, 6.2, 6.3, 6.4, 6.5_

- [x] 2. MSI协议状态转换表设计
  - 填写表1：CPU操作触发的状态转换表（M/S/I状态，PrRd/PrWr操作）
  - 填写表2：侦听总线事务触发的状态转换表（M/S/I状态，BusRd/BusRdX事务）
  - 明确每个转换的总线事务类型和目标状态
  - 明确侦听器需要执行的操作（数据回写、状态降级等）
  - _需求: 1.1, 1.2, 1.3, 1.4, 1.5_

- [x] 3. 实现MSI协议处理器读请求（PrRd）
- [x] 3.1 实现PrRd在M状态的处理逻辑
  - 实现缓存命中时直接读取数据的逻辑
  - 确保状态保持M不变
  - 确保不触发总线事务
  - _需求: 2.1_

- [x] 3.2 实现PrRd在S状态的处理逻辑
  - 实现缓存命中时直接读取数据的逻辑
  - 确保状态保持S不变
  - 确保不触发总线事务
  - _需求: 2.2_

- [x] 3.3 实现PrRd在I状态的处理逻辑
  - 实现缓存缺失时发起BusRd事务的逻辑
  - 设置bus.req为BusRd
  - 设置bus.source为当前缓存ID
  - 等待总线处理后转换到S状态
  - _需求: 2.3_

- [x] 4. 实现MSI协议处理器写请求（PrWr）
- [x] 4.1 实现PrWr在M状态的处理逻辑
  - 实现缓存命中时直接写入数据的逻辑
  - 执行写操作（data = (data + 1) % 16）
  - 确保状态保持M不变
  - 确保不触发总线事务
  - _需求: 2.4_

- [x] 4.2 实现PrWr在S状态的处理逻辑
  - 实现需要独占权限时发起BusRdX事务的逻辑
  - 设置bus.req为BusRdX
  - 设置bus.source为当前缓存ID
  - 等待总线处理后转换到M状态并执行写操作
  - _需求: 2.5_

- [x] 4.3 实现PrWr在I状态的处理逻辑
  - 实现缓存缺失时发起BusRdX事务的逻辑
  - 设置bus.req为BusRdX
  - 设置bus.source为当前缓存ID
  - 等待总线处理后转换到M状态并执行写操作
  - _需求: 2.6_

- [x] 5. 实现MSI协议总线侦听机制
- [x] 5.1 实现侦听BusRd事务的逻辑
  - 实现M状态侦听BusRd：写回数据到总线，转换到S状态
  - 实现S状态侦听BusRd：保持S状态不变
  - 实现I状态侦听BusRd：保持I状态不变
  - 设置bus.data和bus.ctrl标志
  - _需求: 3.1, 3.3, 3.5_

- [x] 5.2 实现侦听BusRdX事务的逻辑
  - 实现M状态侦听BusRdX：写回数据到总线，转换到I状态
  - 实现S状态侦听BusRdX：转换到I状态
  - 实现I状态侦听BusRdX：保持I状态不变
  - 正确处理数据回写和缓存行失效
  - _需求: 3.2, 3.4, 3.5_

- [x] 5.3 确保侦听器优先于内存控制器响应
  - 在总线事务处理规则中先调用所有缓存的Snoop过程
  - 确保侦听器在内存控制器之前完成处理
  - _需求: 3.6_

- [x] 6. 实现MSI协议内存控制器响应
- [x] 6.1 实现内存响应BusRd事务
  - 检查是否有缓存已提供数据（bus.data != -1）
  - 如果没有缓存提供数据，将内存数据写入总线
  - _需求: 4.1, 4.3_

- [x] 6.2 实现内存响应BusRdX事务
  - 检查是否有缓存已提供数据（bus.data != -1）
  - 如果没有缓存提供数据，将内存数据写入总线
  - _需求: 4.2, 4.3_

- [x] 6.3 实现总线事务完成后的清理逻辑
  - 更新请求源缓存的状态和数据
  - 如果有数据写回（bus.ctrl = CtrlFlush），更新内存
  - 清除总线状态（bus.req = BusNone）
  - _需求: 4.4_

- [x] 7. MSI协议验证和调试
- [x] 7.1 编译和运行MSI协议验证器
  - 使用`./mu msi.m`编译Murphi模型
  - 使用`make msi`构建验证器
  - 使用`./msi`运行验证
  - 确认输出"No error found"
  - _需求: 5.5_

- [x] 7.2 验证MSI协议不变式
  - 验证唯一修改者不变式（最多一个M状态）
  - 验证共享一致性不变式（所有S状态数据相同）
  - 验证互斥性不变式（M状态时无S状态）
  - 验证内存一致性不变式（无M状态时S状态与内存一致）
  - _需求: 5.1, 5.2, 5.3, 5.4_

- [x] 7.3 调试MSI协议错误（如果需要）
  - 使用`./msi -tv`查看错误执行轨迹
  - 分析从初始状态到错误状态的状态序列
  - 根据需要简化场景（NUM_CACHE = 2）
  - 添加临时不变式辅助定位问题
  - _需求: 8.1, 8.2, 8.3, 8.4, 8.5_

- [x] 8. 生成MSI协议实验报告
  - 整理MSI状态转换表（表1和表2）

- [x] 9. MESI协议状态转换表设计（选做）
  - 填写表3：CPU操作触发的状态转换表（M/E/S/I状态，PrRd/PrWr操作）
  - 填写表4：侦听总线事务触发的状态转换表（M/E/S/I状态，BusRd/BusRdX/BusUpgr事务）
  - 明确E状态的引入如何减少总线事务
  - 明确BusUpgr事务的使用场景

- [x] 10. 实现MESI协议处理器读请求（PrRd）（选做）
- [x] 10.1 实现PrRd在M和E状态的处理逻辑
  - 实现M状态命中时直接读取的逻辑
  - 实现E状态命中时直接读取的逻辑
  - 确保状态保持不变，不触发总线事务
  - _需求: 10.1_

- [x] 10.2 实现PrRd在I状态的处理逻辑（关键）
  - 实现缓存缺失时发起BusRd事务的逻辑
  - 根据是否有其他缓存响应决定转换到E或S状态
  - 如果bus.ctrl = CtrlNone，转换到E状态（独占）
  - 如果bus.ctrl != CtrlNone，转换到S状态（共享）
  - _需求: 10.2, 10.3_

- [x] 11. 实现MESI协议处理器写请求（PrWr）（选做）
- [x] 11.1 实现PrWr在E状态的处理逻辑（关键优化）
  - 实现E状态命中时直接写入的逻辑
  - 执行写操作并转换到M状态
  - 确保不触发总线事务（MESI的关键优势）
  - _需求: 10.4_

- [x] 11.2 实现PrWr在S状态的处理逻辑（使用BusUpgr）
  - 实现使用BusUpgr事务失效其他副本的逻辑
  - 设置bus.req为BusUpgr（而非BusRdX）
  - 等待总线处理后转换到M状态并执行写操作
  - _需求: 10.5_

- [x] 11.3 实现PrWr在I状态的处理逻辑
  - 实现缓存缺失时发起BusRdX事务的逻辑
  - 设置bus.req为BusRdX
  - 等待总线处理后转换到M状态并执行写操作
  - _需求: 10.6_

- [x] 12. 实现MESI协议总线侦听机制（选做）
- [x] 12.1 实现侦听BusRd事务的逻辑

  - 实现E状态侦听BusRd：写回数据，转换到S状态
  - 实现S状态侦听BusRd：标记有共享副本（bus.ctrl = CtrlFlushOpt）
  - 实现I状态侦听BusRd：保持I状态不变
  - _需求: 11.1, 11.2, 11.5_

- [x] 12.2 实现侦听BusRdX事务的逻辑
  - 实现M状态侦听BusRdX：写回数据，转换到I状态

- [x] 12.3 实现侦听BusUpgr事务的逻辑

  - 确保不需要数据传输（BusUpgr的优势）
  - _需求: 11.4, 11.5_

- [x] 13. 实现MESI协议总线事务处理（选做）
- [x] 13.1 实现BusRd事务的完整处理流程

  - 根据bus.ctrl判断转换到E或S状态

- [x] 13.2 实现BusRdX事务的完整处理流程

  - 更新请求源缓存到M状态并执行写操作

  - _需求: 10.6_

- [x] 13.3 实现BusUpgr事务的完整处理流程

  - 不需要数据传输
